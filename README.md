# مشاريع أورا — Hub + صفحة لكل مشروع

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Web3Forms — صفحات ثابتة جاهزة لـ Vercel.

## المسارات
| المسار | المحتوى |
|---|---|
| `/` | الهَب: هيرو + فورم، المشاريع حسب المنطقة، جدول مقارنة، كتالوج الوحدات (فلتر بالمشروع + ترتيب بالسعر) |
| `/zed-east` `/solana-east` `/zed-west` `/solana-west` `/silversands` | صفحة المشروع: أرقام، عن المشروع، الطروحات، كروت الوحدات، صور، الموقع، المطوّر، FAQ |
| `/#units-zed-east` | يفتح كتالوج الوحدات في الهَب على مشروع محدد (للإعلانات) |
| `/thank-you` | noindex |

## الإعدادات — `lib/config.ts`
مفتاح Web3Forms، الدومين، الرقم، Google Ads ID + conversion labels، لينك One Click.

## البيانات — `lib/data.ts`
كل الأسعار والوحدات والنصوص. أي تعديل هنا يظهر في الهَب وصفحات المشاريع والـ FAQ والـ meta.
- أسعار زد إيست، سولانا إيست، زد ويست، سولانا ويست: من قائمة المتاح (نوفمبر 2026).
- سيلڤر ساندس: `price: null` (السعر عند الطلب) لحين قائمة أسعار مؤكدة.

## الليدز
كل ليد يصل ومعه: المشروع، الاختيار (الطرح/الوحدة)، مكان التسجيل (`hero-zed-east`, `unit-…`, `popup-…`)، `utm_*` و `gclid`.
